# Premium Full-Stack Portfolio

A futuristic, high-fidelity developer portfolio website designed with an **Antigravity and 3D Floating Physics** theme. Built using React, Next.js, Framer Motion, and custom glassmorphism styling.

## 🚀 Features

- **Hero Section**: Sleek 3D-tilting interactive holographic card with an orbiting ring responsive to mouse movements.
- **About Section**: Modern 3-column glassmorphic grid highlighting key development areas (Web, Backend, and Business Software).
- **Skills Section**: Tech stacks floating in zero-gravity that stabilize and glow on hover.
- **Projects Section**: Interactive floating cards with a subtle scroll parallax depth effect.
- **Experience Timeline**: A vertical scroll-linked timeline with glowing dots that scale and change color (Blue, Purple, Pink) dynamically when scrolled into view.

## 🛠️ Tech Stack

- **Framework**: Next.js (App Router)
- **Library**: React
- **Animations**: Framer Motion & Studio Freight Lenis (Smooth Scroll)
- **Styling**: Vanilla CSS Modules (Glassmorphism & Neon Shadows)

## 📦 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/alanbabu10/portfolio.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open in the browser**:
   Navigate to `http://localhost:3000` to view the live app.
